# Зомби Ниндзя

Браузерная мини-игра в духе Fruit Ninja: разрезай летящие зомби-головы пальцем
или мышью, не задевая чёрные черепа с фитилём.

Один файл, без зависимостей и без интернета: `index.html` (Canvas 2D + WebAudio).

## Запуск

Открой `index.html` в браузере на телефоне или компьютере. На мобильном игра
сама просит полный экран и держит экран включённым (там, где это поддерживается).

```bash
open zombie-ninja/index.html
```

## Режимы

| Режим | Правила |
|---|---|
| Классика | 3 промаха, бомбы смертельны |
| Аркада | 60 секунд на максимальный счёт |
| Дзен | без бомб и без проигрыша |

## Управление

Веди пальцем или зажатой левой кнопкой мыши. Одно движение, разрезающее
несколько голов, даёт комбо и бонус. Рекорд сохраняется в `localStorage`.

### Что режем

- зелёные головы — +10;
- серые с бинтами — +15;
- быстрые красноглазые — +20;
- золотые — +50.

Чёрный череп с горящим фитилём резать нельзя.
